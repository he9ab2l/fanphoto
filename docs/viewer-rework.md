# 照片浏览修复与验收 · 2026-09-08

## 依据与范围

- 依据：`~/问题清单.txt`、项目根 `FanPhoto 照片详情页 UI 改动.md`，两份原文不修改。
- 另一份 `~/FanPhoto 图片详情页重构任务提示词.md` 与上述文档有不同的全屏/尺寸要求，不作为本次需求、不覆盖用户点名文档。
- 在 `feat/photo-detail-viewer` 对照 main 修复，不回退整条分支，不改 main，不迁移照片数据。
- 展示为「平铺」「环绕」；环绕是原圆柱的无限滑动照片空间，不是单张轮播。

## 根因与实现方向

1. 分支删除 `.metadata`、`.metadata-facts`、`.attribution` 等排版，字段失去双列对齐。
2. 详情同时使用 JS 尺寸、CSS width/height transition、条件挂载侧栏，布局变化竞争；手机拖拽只移动 grip，没有连续移动面板。
3. 详情只请求 lg，没有使用已加载缩略图作即时预览。测量网络/资源选择，不取消权限校验来换取缓存速度。
4. 桌面左图右信息，约 320px 稳定侧栏，无独立顶部标题/万能底栏；窄屏全屏图片加三态底部面板。
5. 图片按原比例适配可用宽高，全景不放进过高固定画布；侧栏可操作、折叠释放全部宽度。
6. 平铺约束视觉面积和行高变化，保留顺序、不裁切、不丢图、不出界、尾部尽可能铺满矩形；极端数学冲突明确测试。
7. 环绕保留双向拖动/滚轮/键盘；闲置、不可见、打开详情停止动画。

## Skills 与资源

- redesign、apple-design、baseline-ui：修真实回归、层级、对齐和状态，系统字体与真实摄影优先，不加营销文案、装饰卡片、随机颜色或虚构数据。
- fixing-accessibility：可访问名称、现有 Base UI 焦点行为、键盘/触摸可达、退出恢复焦点。
- fixing-motion-performance：不连续动画宽高、不常驻 rAF、不动画大面积 blur，测量与更新分批。
- liquid-glass-ui 及三份参考：CSS 毛玻璃 + 小面积 SVG 背景位移增强，不支持时可读可用；不套参考中的品牌特定酒红/紫罗兰配色。
- Base UI Dialog/Drawer/Tooltip（以实际安装 API 为准），React Bits 玻璃/曲面结构，MingCute 对应功能图标。
- 冲突裁决：明确要求的玻璃允许必要的无彩高光；性能硬约束优先于 blur 动画建议；沿用已有字体和样式体系。
